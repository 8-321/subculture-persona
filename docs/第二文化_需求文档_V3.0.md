| 路径 | 主体 | 能开的功能 | 会砍掉的功能 | 建议 |

## 4. 数据真实性规范（P0 · 本版核心）

### 4.1 四级数据，四种口径

| 级别 | 内容 | 允许来源 | 上屏条件 |
|---|---|---|---|
| **L0 事实** | 文化起源、年份、地点、作品名、机构名、市场数据 | 公开可查来源（媒体、机构报告、官方文档），每条带 URL | 必须带出处；无出处不许写 |
| **L1 自有实测** | 出率、完成率、平均用时、收藏数（本站） | 脚本 / 后台，写明方法与样本量 | 保留方法与日期 |
| **L2 商家录入** | 价格、服务、发货地、尺码 | 商家后台上传，留痕（谁、何时、依据） | 前端标「商家提供」，价格必须有采价时间 |
| **L3 演示样例** | 12 测试 / 12 商品 / 6 店铺 / 8 帖子 / 8 文章里的所有数字 | 只允许开发版与体验版 | 正式版自动隐藏（见 4.3） |

### 4.2 字段级规则（开发照这张表写）

| 字段 | 出现在 | 正式版没来源时显示 | 说明 |
|---|---|---|---|
| `tests[].done` 人测过 | 02 / 18 | 「待接入」 | 真实值 = 报告表 count |
| `products[].price` | 05 / 13 / 23 / 11 | 不显示价格 | 必须带 `priceAt` 采价时间 |
| `products[].sold` 已售 | 13 | 「销量待接入」 | 真实值 = 订单聚合 |
| `shops[].fans` 粉丝 | 13 / 28 / 23 / 11 | 「粉丝数待接入」 | 真实值 = 关注关系实时计数 |
| `shops[].rate` 好评率 | 13 | 不显示 | **评价 ≥ 20 条才显示**，且写「近 30 天」 |
| `shops[].years` 开店年数 | 13 | 不显示 | 以营业执照/入驻审核日期算 |
| `posts[].likes/views/favs` | 22 / 22b / 24 / 23 | 不显示 | 真实值 = 互动表 |
| `articles[].likes` | 10 | 不显示 | 同上 |
| `reports[].matched` 匹配度 | 04 | 正常显示 | 由引擎算出，可复算，属 L1 |
| 维度值 0—100 | 04 | 正常显示 | 同上 |

### 4.3 代码里怎么强制（已落地，不是纸面要求）

1. `app.js` 增加 `resolveDemoStats()`：`envVersion === 'release'` → 关闸；后台已接真实统计（`config.statsFromBackend`）→ 永久关闸。
2. `utils/stat.js` 是**唯一**允许拼数字的地方：`count / fans / shopMeta / rateLine / sold / sourceNote`。关闸后统一返回「待接入」「粉丝数待接入」。
3. 数据层每条示例数据带 `demo: true`（`content.js` 的 `markDemo()`）。
4. `verify.js [9]` 自动拦：档案 14 条齐全、每篇文章有 `https` 出处、示例数据全带 `demo`、**页面里再出现硬编码「好评率 98%」「已售 {{p.sold}}」直接判失败**。

> 实测（2026-10-24，`tools/gate_test.js` 双环境对拍）：
> 开发版 `1.2万人测过 / 粉丝 8,204 · 好评率 98% · 开店 6 年 / 已售 328 件`；
> 正式版 `待接入 / 商家资质已核验 · 评价数据待接入 / 销量待接入`。

### 4.4 禁用清单（写文案、做图、填后台一律适用）

- ✗ 「100% 准确」「心理学认证」「专业心理测评」——测试不是心理诊断，结果页已有常驻声明。
- ✗ 无来源的精确数字：「好评率 98%」「已售 328 件」「8,204 粉丝」「6 年开店」。
- ✗ 「上万人都说准」「本城最火」这类无法核验的比较级。
- ✗ 未经授权使用真实品牌名/商标做商品展示（当前示例品牌为虚构，正式版只展示已入驻商家）。
- ✗ 把编辑观点写成事实（例：「裙撑会让姿态变化」是编辑观察，不能说「研究表明」）。
- ✗ 一年前的价格当现价，必须带采价时间。

### 5.1 14 型文化档案（新增资产，已接进结果页）

`data/realfacts.js`（由 `05-需求V3/真实文化档案_14型.json` 生成，`python miniprogram/tools/build_realfacts.py` 可重建）。

| 置信度 | A=多源一致；B=单一可靠来源；C=社区共识（C 只能用于氛围描述，不得当事实陈述） |
