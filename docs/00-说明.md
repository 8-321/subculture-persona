## 重建 / 复验命令

```bash
cd E:/亚文化小程序开发

python miniprogram/tools/build_realfacts.py                 # JSON → miniprogram/data/realfacts.js
python miniprogram/tools/patch_articles.py                  # 知识库文章_源.js → content.js（幂等）
node verify.js                                              # 44 项自检（含数据真实性 7 项）
node tools/calib_report.js                      # 14 型出率复测
node tools/smoke_test.js                        # 31 项运行时冒烟（假 wx 跑真逻辑）
node tools/gate_test.js                         # 开发版 / 正式版 数字闸门对拍
python "05-需求V3/tools/export_docx_pdf.py" "05-需求V3/第二文化_需求文档_V3.0.md"
```

## 三条不许破的规则

1. **没有来源的数字不许上屏**（`utils/stat.js` 是唯一出口，正式版自动关闸）。
2. **文化事实必须点得开链接**（14 型档案 + 8 篇文章，`verify.js [9]` 会拦）。
3. **价格只由商家录入**，档案与文案里不写价格。
