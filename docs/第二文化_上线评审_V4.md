# 第二文化 · 上线评审 V4

**日期：2026-11-02 ｜ 评审对象：`miniprogram` 1.1.0（31 页）｜ 评审立场：先当批评者，再当交付者**

> 结论先行：**体验版可以上传；正式提审还不能。**
> 不是代码跑不起来，而是三件外部事实还没落地：真实联系邮箱、隐私政策在线 HTTPS 链接、运营主体（另需 ICP 备案与类目确认）。
> 产品层最大的风险也不是“页面不够多”，而是**定位过宽**：测试、档案、社区、商城、商家入驻同时讲，任何一个都不够硬。

### 0.1 三个阻断，不是“稍后优化”

1. **真实联系邮箱**：`miniprogram/utils/site.js` 里仍是 `hello@secondculture.cn` 占位。隐私政策要求可联系到人，不能拿一个可能不存在的邮箱过审。
2. **隐私政策在线 HTTPS 链接**：站内 `pages/legal/legal` 已有正文，但微信后台要填的是**外部可访问链接**。`05-需求V3/legal-site` 已能生成同源 HTML，尚未托管。
3. **运营主体**：隐私政策里的“个人信息处理者”必须能对应到真实主体。个人主体、企业主体、个体工商户，三种写法不同。

> 这三项解决之前，上传只能算“体验版验证”，不能对外说“已上线”。

## 1. 主要矛盾：可信度 vs 变现冲动

### 1.1 主要矛盾是什么

这个产品最稀缺的不是功能，是**可信度**。

- 用户来做测试，是因为想知道“我是谁”；不是因为这里能买东西。
- 用户愿意分享，是因为结果能替他说话；一旦结果像随机分配，分享就变成社交风险。
- 品牌愿意付钱，是因为这里的人**真的相信这套分类**；一旦数字和内容造假，品牌买的只是曝光，不是文化语境。

所以主要矛盾是：**“可核对的文化档案”与“看起来更热闹的增长手段”之间的矛盾。**

主要方面在**可信度**。可信度垮了，流量越大，反噬越快。

### 1.2 三个具体矛盾

| 矛盾 | 表现 | 本轮处理 |
|---|---|---|
| 内容可信 vs 视觉热闹 | 彩色光效、示例销量、假“现货”会让用户误以为是真的 | 删掉现货/七天无理由/销量优先；正式版数字闸门关闭；示例统一标记 |
| 产品完整 vs 资质不足 | 社区、商城、商家入驻都做了，但个人主体/无后台撑不住 | 文案不再承诺审核；投稿只存本机；商家只登记不假装通过 |
| 单机体验 vs 增长闭环 | 报告、名片、档案都在本机，无法统计分享回流 | 埋点只存本机；商业数据必须等后台，不能拍脑袋 |

### 1.3 一句话判断

**现在最该做的不是再加 10 个页面，而是把“测试 → 报告 → 名片 → 档案 → 再测试”这一条链路做到没有假话、没有死路。**

## 2. 苏格拉底七问：逐条自答

### 问一：用户为什么来？

**答：** 因为想知道“我属于哪一种”，而且想被说得准。
**检验：** 首页第一屏必须能在 3 秒内说清“30 题、3 分钟、14 型”。当前首页轮播文案做到了，但首屏主视觉在部分截图里文字被图片压住，需要真机复核对比度。
**动作：** 保持“开始测试”是唯一主 CTA；推荐品类和测试列表都退到第二屏。

### 问二：用户为什么留下？

**答：** 不是因为有商城，而是因为报告和人格档案值得反复看。
**检验：** 结果页现在有：主图、判词、四维展开、文化溯源、同类/反面、单品、建议、阅读、名片。信息够，但**仍然偏长**。
**动作：** 下一轮把“为什么像你”和“可以试试看”改成折叠区；首屏只留“名字 + 判词 + 四维 + 一个出口”。

### 问三：用户为什么分享？

**答：** 因为名片能替他说一句“我是谁”，而且不暴露微信资料。
**检验：** 名片是 750×1180 的档案卡，有编号水印、判词、四维，保存到相册；分享路径落到人格档案页，不是直接落结果页。
**动作：** 继续强化“第 N 号 / 14”的唯一性；下一步可加“同类/反面”小字，但不要放二维码以外的营销信息。

### 问四：用户为什么付费？

**答：** **C 端不该先收费。** 测试是入口，收费会杀死分享。
**检验：** 当前没有支付入口，这是对的；个人主体也开不了微信支付。
**动作：** C 端保持免费；真要收费，只在企业主体下做“深度报告/实体卡片”，且不能影响基础结果。

### 问五：品牌为什么付钱？

**答：** 因为能买到“一群已经用同一套语言描述自己的人”，以及一套可复用的命题测试。
**检验：** 合作页有三档：品牌命题测试 3.8 万起、城市同好局按场、商家年册 1980/年。**这些是价格锚点，不是已验证成交价。**
**动作：** 先做 3 个低成本 pilot，拿到“答题完成率 / 名片保存率 / 分享率 / 内容互动”四张图，再谈年框。

### 问六：如果明天流量涨 10 倍，哪里先坏？

**答：** 内容审核、客服、商家信息、数据统计，四个地方同时坏。
**检验：** 当前没有内容后台、没有审核队列、没有商家后台、没有服务端埋点；社区是示例，投稿只在本机。
**动作：** 流量来之前先补“最小后台”：内容表、举报队列、商家表、事件表。没有这四张表，不要投流。

### 问七：我们最不该做什么？

**答：** 不该做“看起来很热闹的假社区”和“看起来很完整的假商城”。
**检验：** 本轮删掉了假审核、假现货、假销量排序、假“已提交”；把“关注店铺”从“兜底展示 6 家示例店”改为“只显示真正关注过的店”。
**动作：** 正式版如果还是个人主体，就把社区/商城/商家入口收起来，只留测试、档案、名片、法务。**少，但真。**

## 3. 毛泽东式分析：集中优势兵力，打歼灭战

### 3.1 谁是朋友，谁是敌人

- **朋友**：想被理解、想表达审美身份的用户；愿意为“文化语境”付费的品牌；认真做内容的小店。
- **敌人**：不是同类测试产品，而是**不可核对的说法**、**走不通的入口**、**没有后台却假装有**。
- 品牌不是第一天的朋友。没有用户信任，品牌只是来买曝光；先有群众，再有统一战线。

### 3.2 集中优势兵力

当前 31 页里，真正有差异化的是：

1. 14 型人格库 + 4 万次校准；
2. 14 型可溯源文化档案；
3. 黑白档案视觉 + 人格名片；
4. 结果页的“同类/反面/选物/阅读”出口。

这四件事是一支主力部队。社区、商城、商家入驻是地方部队，应该在主力打开局面之后再用，而不是同时铺开。

### 3.3 一分为二

- 好看是优势：它让测试结果有“被收藏”的欲望。
- 好看也是风险：它会让未完成的后台、未核实的数据看起来像真的。
- 所以视觉越强，文案越要诚实；这两件事必须同时成立。

### 3.4 持久战，不是速胜论

- 速胜论：一次提审、全功能上线、马上接品牌。
- 持久战：先用单机版验证“完成率 / 保存率 / 分享率”，再补后台，再开社区，再谈商家。
- 第一仗的目标不是“功能齐全”，是**100 个真实用户里，有多少人保存名片、发给朋友、七天后还记得自己的人格**。

### 3.5 群众路线

不要问“我觉得这个动效好不好”，要问：

- 用户在第几题退出？
- 看完报告后第一件事是截图、分享，还是退出？
- 名片保存后有没有发出去？
- 从朋友分享进来的人，有没有点“测测我是哪一型”？

当前埋点只在本机，能看单个用户，不能看群体。**这是商业化的第一块短板。**

## 4. 审美评审：黑白档案感成立，但有三个隐患

### 4.1 成立的

- 宋体大标题 + 细线 + 黑白墨色，和 MBTI 霓虹风拉开了距离。
- 结果页“档案编号 + 判词 + 四维 + 出处”的结构，像一本可收藏的册子，不像一次性测试。
- 名片用编号水印而不是花哨贴纸，符合“档案”而不是“海报”的定位。

### 4.2 隐患

1. **14 型图片是“物件渲染 + 彩色辉光”**，不是纪实摄影。单张好看，但放在一起像同一套 AI 素材换了颜色。下一步要么换真实纪实静物，要么统一成“暗背景 + 单侧硬光”的棚拍语言；不要靠全站滤镜解决。
2. **结果页信息仍然偏多**。首屏之后连续 6 个模块，用户容易在“为什么像你”处疲劳。折叠是下一轮最值得做的交互。
3. **卡片与页面风格尚未完全同源**。名片是暖白纸感，页面是冷灰；可以保留纸张感作为“可保存物”的差异，但要把编号、字体、留白对齐。

### 4.3 本轮已做的审美修正

- 名片加巨大档案编号水印，14 型分享物有唯一识别。
- 商品页删掉“现货 / 7 天无理由 / 手工制作”三连，改成“仅展示 / 不收款 / 以商家信息为准”。
- 合作页报价改名“报价口径”，不与商品价格闸门混用。
- 店铺主页沿用“宋体店名 + 暗部主图 + 细线信息”，不再用 toast 假装有店铺页。

## 6. 商业模式：三层，不要同时收钱

### 6.1 三层结构

| 层 | 产品 | 收费对象 | 价格锚点 | 成立前提 |
|---|---|---|---|---|
| L1 入口 | 14 型测试 + 报告 + 名片 | C 端免费 | 0 | 完成率、保存率、分享率 |
| L2 内容 | 人格档案 + 知识库 + 选物 | 品牌/商家 | 商家年册 1980/年 | 有稳定流量与内容更新 |
| L3 项目 | 品牌命题测试 / 城市同好局 | 品牌/场地 | 3.8 万起/期；按场 | 有案例、有数据、有交付团队 |

> 价格为合作页现有锚点，**不是已验证成交价**。第一年目标不是“卖贵”，是“做出 3 个可公开的案例”。

### 6.2 单位经济模型（先写公式，不填假数）

- 品牌命题测试毛利 = 合同额 −（题目共创 + 视觉 + 开发 + 内容 + 运营 + 渠道）。
- 商家年册毛利 = 1980 −（访谈 + 拍摄 + 编辑 + 客服 + 内容分发）。
- C 端获客成本应接近 0：靠名片分享与档案页自然回流；一旦需要投流，先检查分享率是否低于 3%。

### 6.3 增长闭环

```
测试 → 报告 → 保存名片 → 分享给朋友 → 朋友打开人格档案
     → “测测我是哪一型” → 新测试 → 新报告
```

闭环的瓶颈不在“有没有分享按钮”，在**名片是否值得发**。所以第一指标不是日活，是：

1. 测试完成率（开始 / 答完）；
2. 名片保存率（答完 / 保存）；
3. 分享率（保存 / 分享）；
4. 档案页到测试的开始率；
5. 7 天回访率。

### 6.4 Go / No-Go 门槛（假设，需用真实数据校准）

| 指标 | 低于此值：先别投流 | 高于此值：可以小规模投放 |
|---|---|---|
| 测试完成率 | < 40% | > 55% |
| 名片保存率 | < 8% | > 15% |
| 分享率 | < 3% | > 8% |
| 档案页 → 开始测试 | < 5% | > 12% |
| 7 天回访 | < 10% | > 20% |

> 这些是运营假设，不是实测。没有服务端埋点之前，不要对外引用。

## 7. 上线路线：A / B / C 三条路

### A. 企业主体 + ICP + 社区类目（全功能）

- 能开：31 页全量、社区、商家、后续支付。
- 代价：备案 20 个工作日起、社区审核、内容审核人力、商家后台。
- 适合：确定要做成生意，且能承担内容运营。

### B. 单机版先上线（推荐现在走）

- 保留：测试、报告、人格档案、名片、知识库、法务、我的。
- 收起：社区投稿、商城交易暗示、商家入驻、关注店铺。
- 主体：个人/个体工商户均可先跑；不承诺社区与交易。
- 代价：需要 1 天做入口收口（tabBar 从 5 个减到 3–4 个，隐藏 3 个入口）。
- 好处：**今天就能把“可信的测试产品”交给用户**，不拿资质赌审核。

### C. 只做作品集（不追求上线）

- 保留全部视觉与交互，明确标注“演示”。
- 不适合获取真实用户与品牌合作。

> 我的建议：**先走 B，拿到 100 个真实用户数据，再升级 A。** 不要用 A 的野心拖住 B 的上线。
